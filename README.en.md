# Nama Studio

The repository of the "Nama Studio" portal site, where my self-made apps are published.

## Links
- Site: https://nama1223.com/
- Nama Studio top: https://nama1223.com/

## Contents
- index.html: the top page (app list, author profile, a "Writing" tab, and more)
- Store/: store pages and screenshots for each app
- TopPageMaker.html / StorePageMaker.html: my own tools for building the top page and store pages

The apps are mainly music tools (metronome, tuner, recording section player, etc.) and handy utilities. See each app's repository README and its store page on the site for details.
