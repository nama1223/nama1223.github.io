# Nama Studio ─ナマスタ─

自作アプリの公開ポータル「Nama Studio」のサイト本体のリポジトリです。

## リンク
- サイト: https://nama1223.com/
- Nama Studio トップ: https://nama1223.com/

## 中身
- index.html: トップページ（アプリ一覧、作者紹介、「文章」タブなど）
- Store/: 各アプリの紹介ページとスクリーンショット
- TopPageMaker.html / StorePageMaker.html: トップページと紹介ページを作るための自作用ツール

公開しているアプリは、音楽系（メトロノーム、チューナー、録音の区分け再生など）と便利ツールが中心です。各アプリの詳細は、それぞれのリポジトリのREADMEと、サイト内の紹介ページをご覧ください。
